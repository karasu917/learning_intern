# learning_intern
本文件用于学习agent开发实习所需要的技能

目前学习内容：

1. requests库代码调用大模型API，实现了按错误类型区分的重试机制（指数退避+随机抖动）

2. 完成一个论文摘要生成器：将论文按句子边界切分成若干文本块，逐块生成摘要，在合并成总摘要，并统计token和耗时
   
   · 项目的结构为：
   
       1.llm.py:调用大模型API，返回生成内容和token用量。网络异常，429，5xx采用指数退避重试；401等客户端错误直接报错。

       2.reader.py:用pypdf提取PDF文本并清洗，拼接行末被连字符拆开的单词，把换行和连续空白合并成单个空格。

       3.splitter.py:按中英文句末标点拆分句子 再以完整句子为单位装成长度不超过上限的文本块，相邻块重叠一句以保持上下文；超长句硬切兜底。

       4.summarizer.py:逐块调用模型生成分段摘要（map），在合并为总摘要（merge）；分段摘要过长时递归分组压缩。同时累加每次调用的token用量。

       5.main.py：串联整个流程，统计总耗时并输出结果。

   · 数据流为：PDF → reader 提取并清洗文本 → splitter 拆句、装块 → summarizer 逐块生成摘要 → 合并为总摘要 → main 打印总摘要、总 token 数和总耗时。

       关键设计：
   
       · 以句子为最小单位装块，避免句子被切断；块间重叠一句，减少跨块的上下文丢失。

       · 采用map-reduce，解决长文档超出模型上下文，以及一次性处理时重点丢失的问题。

   ·运行结果：页数/块数/调用次数/总token/总耗时

   ·已知局限：缩写会被误切句；双栏论文提取顺序可能错乱：长度按字符而非token计算；各块串行调用较慢，下一步尝试并发调用。
