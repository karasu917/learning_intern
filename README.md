# learning_intern
本文件用于学习agent开发实习所需要的技能

目前学习内容：

1. requests库代码调用大模型API

2. 完成一个论文摘要生成器，功能为：大模型通过读取论文中的每一段，来为其逐段生成摘要，最后将这些整合成总摘要输出。

   · 项目的结构为：
   
       1.llm.py:负责进行大模型api的调用，发送请求，处理返回结果，同时具有重试和错误处理机制。

       2.reader.py:负责调用PDF阅读器，提取并清理论文中的文本，删除多余的空格换行符连字符。

       3.splitter.py:负责把PDF阅读器提取出的文本内容先进行分句，按照中英文的结尾标点符号划分句子，把句子限制大小装入列表中

       4.summarizer.py:主要负责将分段的摘要整合成总摘要，并计算任务总消耗token和时长

   · 数据流为：先把PDF文件上传给阅读器提取文本后，交给splitter处理，获取干净的句子为单位的文本，之后按部分上传给summarize文件，组成prompt传给大模型进行总结，之后将每部分摘要合成总摘要，总消耗token数，总时长，最后由大模型返回给用户。
